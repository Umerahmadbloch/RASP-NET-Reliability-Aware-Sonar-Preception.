# RASP-NET-Reliability-Aware-Sonar-Preception.
RASP-Net: Reliability-Aware Sonar Object Detection  A reliability-guided sonar object detection framework that learns a single **unified reliable-object-evidence** representation to guide feature refinement, query refinement, adaptive loss weighting, and calibrated confidence estimation.
